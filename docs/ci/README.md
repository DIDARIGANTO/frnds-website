# Автосборка на GitHub

Здесь лежит готовая настройка автосборки: при каждой правке GitHub сам
прогоняет тесты, собирает сайт и складывает готовую папку архивом,
который можно скачать и залить на хостинг.

Файл лежит не на своём месте намеренно: чтобы положить его в
`.github/workflows/`, у программы `gh` должно быть отдельное разрешение
`workflow`, а его выдают только вручную.

## Как включить

Одна команда — она откроет браузер и попросит подтвердить доступ:

```bash
gh auth refresh -s workflow
```

Затем перенести файл на место и отправить на GitHub:

```bash
cd "/Users/didar/Desktop/тут сайты /Frnds" && mkdir -p .github/workflows && git mv docs/ci/build.yml .github/workflows/build.yml && git commit -m "ci: автосборка сайта" && git push
```

После этого во вкладке **Actions** в репозитории будет появляться свежая
сборка после каждой правки, а собранный сайт — во вложении к ней.

## Зачем это нужно

Сейчас, чтобы обновить сайт, нужно у себя на компьютере выполнить
`python3 build.py` и залить папку `dist` на хостинг. С автосборкой
достаточно поправить цену в `data/menu.json` прямо на сайте GitHub —
сборка запустится сама, а вам останется скачать готовый архив.

Если сайт будет жить на Netlify, Vercel или Cloudflare Pages, автосборка
тоже не помешает: она ловит опечатки в данных до того, как их увидит гость.
