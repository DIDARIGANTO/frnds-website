# Как обновлять сайт Frnds

Инструкция для владельца. Технических знаний не требуется — нужен только
Терминал на компьютере с сайтом и любой текстовый редактор.

## Главное правило

Сайт собирается из данных. Вы правите один файл — и цена меняется сразу
на русской, казахской и английской версии, на главной, в меню и на странице
блюда. Вручную по страницам ходить не нужно.

После любой правки выполните одну команду:

```bash
python3 build.py
```

Появится сообщение «Собрано страниц: 78». Готовый сайт лежит в папке `dist` —
её содержимое и заливается на хостинг.

Если вместо этого вы увидели красную строку «Ошибка в данных: …» — значит,
в файле опечатка. В сообщении написано, в каком именно блюде и что не так.
Исправьте и запустите команду снова. Пока ошибка не исправлена, старый сайт
работает как работал: сборка не портит то, что уже загружено.

## Посмотреть, что получилось, до заливки

```bash
python3 -m http.server -d dist 8000
```

Откройте в браузере `http://localhost:8000`. Чтобы остановить просмотр —
нажмите в Терминале Ctrl+C.

## Поменять цену

Откройте `data/menu.json`, найдите блюдо по названию (поиск по файлу:
Cmd+F) и поправьте число в строке `"price"`.

```json
"price": 3590,
```

Пишите только цифры: без пробелов, без знака тенге, без копеек.
`3590` — правильно. `"3 590 ₸"` — сломает сборку.

## Добавить новое блюдо

Скопируйте любой соседний блок в `data/menu.json` и поправьте поля:

```json
{
  "id": "pizza-4-cheese",
  "category": "pizza",
  "price": 4290,
  "name": { "ru": "Четыре сыра", "kk": "Төрт ірімшік", "en": "Four cheese" },
  "desc": {
    "ru": "Моцарелла, горгонзола, пармезан и чеддер на сливочном соусе.",
    "kk": "Кілегейлі тұздықтағы моцарелла, горгонзола, пармезан және чеддер.",
    "en": "Mozzarella, gorgonzola, parmesan and cheddar on a cream sauce."
  }
}
```

Обязательные поля: `id`, `category`, `price`, `name` и `desc` на всех трёх
языках. `id` — любое короткое имя латиницей, но обязательно не такое,
как у других блюд. `category` — из списка в начале файла (`pizza`,
`breakfast`, `coffee` и так далее).

Если перевода пока нет, всё равно впишите что-нибудь во все три языка —
сборка не пропустит блюдо с пустым переводом, и это защита от того,
чтобы на казахской версии сайта появилась пустая строка.

## Убрать блюдо из меню

Удалите его блок целиком, вместе с фигурными скобками и запятой после них.
Проверьте, что после удаления не осталось двух запятых подряд.

## Добавить фотографию блюда

Сейчас фотографии есть только у 13 пицц. Чтобы добавить фото другому блюду:

1. Положите снимок в папку с исходниками. Снимайте сверху, на светлом фоне,
   квадратом — так же, как сняты пиццы.
2. Запустите: `python3 tools/prepare_images.py <путь-к-папке-со-снимками>`
   Скрипт сам обрежет квадрат и сделает три размера в двух форматах.
3. В `data/menu.json` у нужного блюда добавьте строку `"photo": "имя-файла"`
   (без расширения и без размера).

Блюда без фотографии показываются аккуратным списком с названием, составом
и ценой — это сделано намеренно, пустых серых прямоугольников на сайте нет.

## Поменять телефон, адрес или часы работы

Всё в `data/site.json`. Обратите внимание: телефон записан дважды —
в `phone` (для кнопки «позвонить», со знаком плюс) и в `whatsapp`
(для ссылки на переписку, без плюса и без пробелов).

## Вписать домен

Когда купите домен, в `data/site.json` поправьте одну строку:

```json
"domain": "https://frnds.kz",
```

и пересоберите сайт. Это автоматически починит карту сайта для Google,
ссылки между языковыми версиями и разметку для поисковиков. До этого
момента сайт работает, но поисковики видят его хуже.

## Добавить ссылки на агрегаторы доставки

В `data/site.json` заполните список:

```json
"aggregators": [
  { "name": "Glovo", "url": "https://glovoapp.com/..." },
  { "name": "Wolt", "url": "https://wolt.com/..." }
]
```

Пока список пустой, блок с агрегаторами на сайте не показывается —
чтобы не отправлять гостя по несуществующей ссылке.

## Поменять фото команды и гостей

Полароиды на главной, в блоке «Дом вне дома» и на странице «Наш дом»
лежат в `src/img/team/` — по три размера на каждый снимок. Чтобы заменить
или добавить кадр: положите новый полароид (с рамкой, как у текущих)
в папку с исходниками, нарежьте его тем же способом, что и фото пицц,
и впишите имя файла в `build/pages/home.py` (словарь `POLAROID_ALT`
и вызовы `polaroid(...)`).

## Поменять тексты на страницах

Папка `data/pages/`, по файлу на страницу и язык. Например,
`home.ru.json` — русская главная, `geo-esil.kk.json` — казахская
страница про Есильский район.

Меняйте только текст внутри кавычек. Названия полей слева от двоеточия
(`seo_title`, `hero_text` и прочие) трогать нельзя.

## Проверить, что ничего не сломалось

```bash
./run_tests.sh
```

Тесты проверяют, что все блюда на месте, переводы не потерялись,
цвета остались читаемыми, а ссылки между языками ведут куда надо.
Если всё хорошо, последняя строка — `OK`.
