# Как опубликовать сайт в интернете

Сейчас сайт живёт в приватном репозитории на GitHub:
https://github.com/DIDARIGANTO/frnds-website

Это исходники. Чтобы сайт открывался по ссылке у гостей, его нужно
подключить к хостингу. Ниже — самый простой бесплатный способ.

## Cloudflare Pages

Работает с приватным репозиторием, сам пересобирает сайт после каждой
правки, выдаёт бесплатный адрес и HTTPS. Свой домен подключается позже.

### Шаг 1. Аккаунт

Открыть https://dash.cloudflare.com/sign-up и завести аккаунт
(или войти, если он уже есть). Карта не нужна.

### Шаг 2. Создать проект

В левом меню: **Workers & Pages** → кнопка **Create** → вкладка **Pages** →
**Connect to Git**.

Cloudflare попросит доступ к GitHub. Выбрать аккаунт **DIDARIGANTO** и
разрешить доступ к репозиторию **frnds-website** (можно выбрать только его,
а не все репозитории).

### Шаг 3. Настройки сборки

Заполнить ровно так:

| Поле | Значение |
|---|---|
| Project name | `frnds` |
| Production branch | `main` |
| Framework preset | `None` |
| Build command | `python3 build.py` |
| Build output directory | `dist` |
| Root directory | оставить пустым |

Раскрыть **Environment variables (advanced)** и добавить одну переменную:

| Имя | Значение |
|---|---|
| `PYTHON_VERSION` | `3.11` |

Без неё Cloudflare возьмёт старую версию Python, и сборка может упасть.

### Шаг 4. Запустить

Нажать **Save and Deploy**. Первая сборка занимает две-три минуты.
В логе должна появиться строка `Собрано страниц: 69` — это значит,
что всё прошло правильно.

Готовый сайт откроется по адресу вида `https://frnds.pages.dev`.

### Дальше: свой домен

Когда купите домен, в проекте Cloudflare: **Custom domains** → **Set up a
domain** → ввести адрес. Сертификат HTTPS выпустится сам.

После этого поправьте домен в `data/site.json` (поле `domain`) и отправьте
правку на GitHub — сайт пересоберётся сам, а поисковики получат правильные
ссылки на языковые версии.

## Как обновлять сайт после публикации

Поправить данные (например, цену в `data/menu.json`), отправить на GitHub:

```bash
cd "/Users/didar/Desktop/тут сайты /Frnds" && git add -A && git commit -m "цены" && git push
```

Cloudflare увидит правку и пересоберёт сайт сам за пару минут.
Собирать у себя на компьютере больше не нужно.

## Если не подходит Cloudflare

- **Netlify** — то же самое, настройки те же: команда `python3 build.py`,
  папка `dist`. Файл `src/_headers` там тоже работает.
- **GitHub Pages** — бесплатно только для публичного репозитория. Если
  сделать репозиторий открытым, сайт заработает по адресу
  `didariganto.github.io/frnds-website`.
- **Обычный хостинг** — собрать у себя `python3 build.py` и залить
  содержимое папки `dist` по FTP. Никакого Python на хостинге не нужно:
  там лежат обычные HTML-файлы.
